# Number Guessing Game in C

## Description

A simple number guessing game developed using the C programming language. The program generates a random number, and the user tries to guess it.

## Features

* Generates a random number between 1 and 100.
* Accepts guesses from the user.
* Indicates whether the guess is too high or too low.
* Counts the number of valid guesses.

## Technologies Used

* C Programming
* Standard C Library

## How to Run

1. Compile the source file using a C compiler.
2. Run the generated executable.
3. Enter guesses between 1 and 100.
